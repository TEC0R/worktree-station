# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/TEC0R/worktree-station/security/advisories/new).
Include what you found, how to reproduce it, and its impact.

You will get an answer as soon as possible. Once a fix is released, the
advisory is published with credit to the reporter, unless you prefer to stay
anonymous.

## Supported versions

Only the latest commit of the default branch (`staging`) is supported.
